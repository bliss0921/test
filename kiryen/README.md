# 로판세계에서 살아남는법 — 원작 타임라인 분리

원칙: **플레이어는 다 알아도 되고, NPC는 원작(과 이게 소설이라는 사실)을 모른다.**
모델은 이 세계가 소설 속이라는 건 알지만, 그건 {{user}}의 독자 기억으로만 다루고,
미래 이벤트는 **지금까지 진행된 일 + 7일 안에 다가온 일**만 받는다.

## 적용 방법 (코딩 몰라도 됨)

`로판세계에서 살아남는법_타임라인적용.charx` 를 RisuAI에서 불러오면 끝.
왼쪽 캐릭터 목록의 **+** 버튼 → **캐릭터 임포트** → 이 파일 선택.

- 새 캐릭터로 하나 더 생기고, 원래 캐릭터와 채팅은 그대로 남는다.
  새 캐릭터로 새 채팅을 시작해서 확인한 뒤, 괜찮으면 옛 캐릭터를 지우면 된다.
- 이 파일은 처음 보내 준 카드 기준이다. 그 뒤에 RisuAI에서 고친 내용은 들어 있지 않다.

이 파일 안에서 바뀐 것:

| 바뀐 곳 | 내용 |
|---|---|
| 트리거 스크립트 | `원작 타임라인` 트리거 추가 (`원작타임라인.lua`). 기존 트리거는 그대로 |
| 로어북 `원작소설` | `로어북_원작소설.md` 로 교체 |
| 로어북 `Status` | `로어북_Status.md` 로 교체 (모델이 UPCOMING을 안 씀) |
| 로어북 `빙의상태 키르엔 설정` | `#### Basic` 아래에 `로어북_능력비밀.md` 추가 |
| 로어북 `100일 타이머` | 상시 활성 끔 → 모델에 안 들어감. 이름만 `100일 타이머(안내용 · 모델에 안 들어감)` 으로 |
| 정규식 `Status` | STATUS에 UPCOMING이 없어도 카드가 그려지게 |
| 정규식 `Status 리퀘제거` | UPCOMING 없는 새 STATUS도 오래된 것은 정리되게 |

직접 손으로 넣고 싶으면 위 표대로 각 파일 내용을 해당 칸에 붙여 넣으면 된다.
트리거는 캐릭터 설정의 **트리거 스크립트**에서 새로 하나 만들고 Lua 코드 칸에 `원작타임라인.lua` 내용을 붙여 넣는다.

## 동작

- **모델에게**: 요청 직전에 `[World State]` 메모를 마지막 유저 메시지 앞에 끼워 넣는다.
  이미 진행된 이벤트, 막힌 이벤트, 7일 안에 다가온 이벤트만 들어가고, 비밀 이벤트에는
  `known only to` (아는 사람 목록)가 붙는다. 채팅 기록에는 남지 않는다.
- **플레이어에게**: 화면에서 STATUS 줄 끝에 UPCOMING을 자동으로 붙여 보여 준다.
  저장된 메시지에는 없으므로 모델은 못 본다. 첫 메시지에 직접 적어 둔 UPCOMING은
  화면엔 그대로 보이고, 모델에게 보낼 때만 지워진다.
- **날짜**: 마지막 응답 STATUS의 `IY: 429. 7.15` 같은 날짜로 계산한다.
- **막기**: {{user}}가 이벤트를 불가능하게 만들면 모델이 응답 STATUS 앞에
  `<!-- TIMER: E4 blocked -->`를 남긴다. 그 이벤트에 의존하는 뒤 이벤트도 같이 막힌다.
  모델이 놓치거나 잘못 붙이면 플레이어가 메시지를 수정해서 주석을 직접 넣거나 지우면 된다.
- 상태는 저장하지 않고 매번 채팅 기록에서 다시 계산하므로 리롤·삭제·분기에 안전하다.
