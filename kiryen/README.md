# 로판세계에서 살아남는법

원칙: **플레이어는 다 알아도 되고, NPC는 원작(과 이게 소설이라는 사실)을 모른다.**
모델은 미래 이벤트 중 **지금까지 진행된 일 + 7일 안에 다가온 일**만 받는다.

`로판세계에서 살아남는법_v4.charx` 는 v4로 넘긴 그대로의 카드다. 그 뒤로는 사용자가 카드를 직접 고치고(로어북 이름 정리, 외모 커스텀용 빙의상태 로어북 등),
아래 '운명의 개입·원작 줄거리' 변경도 사용자가 직접 붙여 넣는다. 그래서 최신 상태는 사용자 카드이고, 이 폴더의 `원작타임라인.lua`(Lua 칸 전체)·`토글.txt`(토글 칸 전체)·`로어북_상태창.md`·`로어북_유저빙의_다른사람.md`·`로어북_원작소설.md`·`로어북_운명의개입.md`(각 로어북 내용 전체)가 붙여 넣을 원본이다.

## v4: 설정은 커스텀 토글로

언어·빙의·난이도·성별·프로필을 전부 사이드바 **커스텀 토글**에서 고른다. 사이드 성별 패널(⚧)과
시작 화면의 언어·시나리오·난이도 버튼은 없앴다. 토글 값은 모든 채팅에 공통이다.

토글을 한 번도 안 고르면 칸이 비어 보이고, 그때는 아래 '안 고르면' 값으로 동작한다.

| 토글 | 바뀌는 것 | 안 고르면 |
|---|---|---|
| `kc_language` 언어 | 첫 메시지, 시작 화면 글자, 상태창 라벨(능력·다가올 일 / Ability·Upcoming)과 이벤트 이름, 상태창 지침의 출력 언어·예시 | 한국어 |
| `kc_scenario` 빙의 | 카르엔야에 빙의: 빙의 전제·빙의상태 설정 / 다른 인물에 빙의: 다른 인물 전제 / 빙의 없음: 전제 로어북 없음 ({{user}}는 페르소나 그대로). 다른 인물·빙의 없음이면 오리지널 카르엔야 프로필과 NPC 목록의 카르엔야 줄이 켜지고, 첫 메시지는 자유 시작이 된다. 빙의 없음이면 `원작소설`의 '소설과 이 세계' 부분과 트리거 메모의 '독자의 기억' 문구가 빠진다 | 카르엔야에 빙의 |
| `kc_fate` 운명의 개입 | 보통·강하게: 막은 사건이 다른 길로 다시 시도된다. 막힘 표시가 2번(강하게는 3번) 쌓여야 진짜 막힌다. `운명의개입` 로어북(운명이 작용하는 방식)이 켜진다 / 끄기: 1번에 막힘 | 보통 |
| `kc_plot` 원작 줄거리 | 다가올 때만: AI는 지난 일 + 7일 안의 일만 안다 / 전부: 앞으로의 줄거리와 결말까지 안다 / 없음: 원작 사건 없이 자유롭게 (World State 안 보냄, 상태창 D-day·다가올 일 없음, 상태창 지침에서 D-XX 빠짐, 다른 인물 전제의 100일 문단·원작소설의 카운트다운 언급·운명의 개입 꺼짐. 소설 틀은 남음). '없음'은 빙의가 다른 인물·빙의 없음일 때만, 카르엔야 빙의면 다가올 때만으로 동작 | 다가올 때만 |
| `kc_g_…` 성별 | NPC 목록의 male/female·키, ♂/♀ 상세 프로필 중 어느 쪽이 켜질지 | 원작 성별 (카르엔야·다프네야 여, 나머지 남) |
| `kc_p_…` 프로필 | 리스트만: ♂/♀ 상세 프로필을 끈다. NPC 목록 줄은 남는다 | 상세 |

토글 값은 고른 선택지의 번호다 (첫 번째 0, 두 번째 1, 세 번째 2). CBS에서는
`{{#when::kc_language::tis::1}}영어일 때{{:else}}한국어일 때{{/when}}` 처럼 쓴다.
'안 고름'은 `null` 이라서, 기본값 쪽은 `tisnot` 으로 적었다 (예: 남이 기본인 인물의 남자 조건 `kc_g_hedwig::tisnot::1`,
여가 기본인 인물의 여자 조건 `kc_g_karenya::tisnot::0`).

### 시작 화면 (퍼메)

- 버튼은 두 개: `{{user}}가 카르엔야에 빙의` (빙의 토글이 카르엔야일 때만 보임), `자유 시작`.
- 자유 시작을 누르거나 빙의 토글이 다른 인물·빙의 없음이면 첫 메시지는 빈 상태창 `[IY: ? | ? | ? | ?]` 만 남는다.
- 영어 첫 메시지 본문은 아직 `English Karenya first message content` 자리표시다. 그 아래 영어 상태창 줄은 넣어 두었다.

### 상태창

모델은 한 줄만 쓴다 (로어북 `Status`):

```
[IY: 429. 7.15 (D-68) | 15:00 | 기사단 연무장 | 시간 정지 || 헤드비히 | 속마음 || 루스란 | 속마음]
```

`||` 뒤는 장면에 있는 인물마다 `이름 | 속마음`. 아무도 없으면 `||` 부분 없이 끝난다.
화면에서는 트리거가 이 줄을 모서리 컷 카드로 그린다 (날짜 + D-day / 시간 · 장소 · 능력 / 속마음 / 다가올 일 3개).
D-day와 다가올 일은 날짜로 트리거가 계산하므로 모델이 틀리게 써도 화면은 맞다. 날짜가 `?` 이면 다가올 일은 안 나온다.
카드 모양 CSS는 배경 HTML 맨 아래 `.ks…` 부분이고, 테두리 그림은 CSS 안에 들어 있어서 에셋 파일이 필요 없다.

정규식 `Status 리퀘제거` 는 AI에게 보낼 때 옛 상태창을 `[IY: 날짜 | 시간 | 장소]` 로 줄여 토큰을 아낀다 (능력·속마음 삭제).
최근 메시지 4개(보통 AI 답변 2개)는 모델이 형식을 따라 쓰도록 그대로 보낸다. 저장된 채팅과 화면은 바뀌지 않는다.
인물 이름을 하나하나 적지 않고 "세 번째 칸 뒤 전부"를 지우는 방식이라, 등장인물이 몇 명이든 같은 식 하나로 된다.
옛 `Status` 표시 정규식과 성별 패널 정규식 2개는 없앴다.

## 트리거가 하는 일

Lua 칸 전체 = `원작타임라인.lua` (퍼메 버튼 함수 `setPermaKarenya`, `setPermaFree` + 원작 타임라인 + 운명의 개입 + 상태창). 고칠 때는 Lua 칸을 통째로 바꿔 붙인다.
RisuAI가 Lua에게 끼어들 기회를 주는 순간 중 두 개를 쓰고, 변수는 저장하지 않는다.

1. **AI에게 보내기 직전** (`editRequest`)
   - 가장 최근 AI 답변의 STATUS 날짜로 9월 21일까지 남은 날을 계산한다.
   - 지난 일 + 7일 안 일만 `[World State]` 메모로 써서 마지막 유저 메시지 앞에 끼운다. 먼 미래는 안 들어간다
     (원작 줄거리 토글이 '전부'면 결말까지 다 넣는다).
   - 메모는 채팅에 저장되지 않고 보낼 때마다 새로 만든다 → 리롤·삭제해도 안 꼬인다.
2. **화면에 그릴 때** (`editDisplay`)
   - STATUS 줄을 상태창 카드로 바꿔 그린다. 다가올 일은 그 메시지 날짜와 그때까지의 막힘 표시 기준이다.

**막힘 표시**: 유저 행동으로 이벤트가 불가능해지면 AI가 상태창 앞에 `<!-- TIMER: E2 blocked -->`를 쓴다.
화면엔 안 보이고, 메시지 수정 화면에서는 보이므로 직접 넣거나 지울 수 있다.
그 이벤트를 전제로 하는 뒤 이벤트(`needs`)도 같이 막힌다. 표시는 그 일이 일어난 답변에 한 번만 쓴다.

**운명의 개입** (보통·강하게): 첫 막힘 표시는 '좌절'일 뿐이다. 막힌 날(그 사건 날짜가 더 늦으면 사건 날짜)부터 5일(`REBOUND_DAYS`) 안에
같은 결과가 다른 길로 다시 시도된다. AI 메모에는 'Fate pushes back' 칸에 기한과 함께 나오고, 상태창 '다가올 일' 맨 위에
`곧 · 다프네야 → 피아체 접촉 (다른 길로)` 처럼 뜬다. 유저가 그것까지 막으면 AI가 표시를 한 번 더 쓰고, 2번(강하게는 3번)이 되면 진짜 막힌다.
기한 안에 다시 못 막으면 그 일은 결국 다른 길로 일어난 것으로 친다. 되돌리는 중에는 뒤 이벤트도 막히지 않는다.

## 이벤트 고치기

`원작타임라인.lua` 의 `EVENTS` 표 한 줄이 이벤트 하나다.

```lua
{ id = "E2", day = 75, date = "7.08", title = "다프네야 → 루스란 접촉", title_en = "Daphneya → Ruslan", knows = "Daphneya, Ruslan", needs = {"E0"},
  plot = "Through a familiar, Daphneya delivers a note to Ruslan saying that Runian is alive." },
```

| 칸 | 뜻 |
|---|---|
| `id` | 이름표. 막힘 표시에 쓴다 |
| `day` / `date` | D-몇 / 날짜 |
| `title` / `title_en` | 화면 '다가올 일'에 나오는 이름 (한국어 / 영어). `title_en` 은 AI 메모에도 쓴다 |
| `knows` | 아는 사람. 없으면 공개 행사 |
| `needs` | 이게 막히면 같이 막힘 |
| `plot` | AI에게 보내는 내용 |

따옴표 `"`, 쉼표 `,`, 중괄호 `{ }`는 지우지 않는다. `WINDOW = 7`은 며칠 전부터 알려 줄지,
`UPCOMING_COUNT = 3`은 화면에 몇 개 보여 줄지, `REBOUND_DAYS = 5`는 운명이 며칠 안에 다시 시도할지.
