# 로판세계에서 살아남는법 — 원작 타임라인 분리

원칙: **플레이어는 다 알아도 되고, NPC는 원작(과 이게 소설이라는 사실)을 모른다.**
모델은 이 세계가 소설 속이라는 건 알지만, 그건 {{user}}의 독자 기억으로만 다루고,
미래 이벤트는 **지금까지 진행된 일 + 7일 안에 다가온 일**만 받는다.

## 직접 넣는 방법

### 1. 트리거 (Lua)

캐릭터 설정 → **트리거 스크립트** → Lua 칸.
이미 들어 있는 코드(언어·시나리오·성별 버튼)는 그대로 두고, **맨 끝에 한 줄 띄운 뒤**
`원작타임라인.lua` 내용을 통째로 붙여 넣는다.

RisuAI 화면에는 Lua 칸이 하나만 보이므로 트리거를 따로 새로 만들지 않는다.
따로 만들면 동작은 해도 화면에서 보이지 않는 코드가 된다.

### 2. 로어북

| 항목 | 할 일 |
|---|---|
| `100일 타이머` | **상시 활성 끄기** (키는 비워 둔 채). 작성지침처럼 모델에 안 들어간다 |
| `Status` | `로어북_Status.md` 로 교체. 모델이 UPCOMING을 안 쓰게 된다 (화면에는 트리거가 붙여 줌) |
| `원작소설` | `로어북_원작소설.md` 참고해서 교체 |
| `빙의상태 카르엔야 설정` | `#### Basic` 아래에 `로어북_능력비밀.md` 추가 |

### 3. 정규식

**`Status 리퀘제거`** (고쳐야 함) — IN 칸을 아래로 교체. 안 고치면 UPCOMING 없는 새 상태창이
정리되지 않아 토큰만 늘어난다 (고장은 아님).

```
\s*\|\s*ABILITY:\s*[^\|\]\r\n]*\s*\|\s*PRESENT:\s*[^\|\]\r\n]*(?:\s*\|\s*UPCOMING:\s*[^\]\r\n]*)?
```

**`Status`** (선택) — 트리거가 UPCOMING을 붙여 주므로 안 고쳐도 된다. 고쳐 두면 트리거를 빼도
상태창 카드가 깨지지 않는다.

```
\[IY:\s*([^\|]+?)\s*\|\s*TIME:\s*([^\|]+?)\s*\|\s*LOCATION:\s*([^\|]+?)\s*\|\s*ABILITY:\s*([^\|]+?)\s*\|\s*PRESENT:\s*([^\|]+?)\s*(?:\|\s*UPCOMING:\s*([^\]]+?)\s*)?\]
```

## 트리거가 하는 일

RisuAI가 Lua에게 끼어들 기회를 주는 순간 중 두 개만 쓴다. 변수는 저장하지 않는다.

1. **AI에게 보내기 직전** (`editRequest`)
   - 가장 최근 AI 답변의 STATUS 날짜(`IY: 429. 7.15`)로 9월 21일까지 남은 날을 계산한다.
   - 코드 맨 위 `EVENTS` 표와 비교해 "지난 일 / 7일 안 / 그보다 먼 일"로 나눈다.
   - 지난 일 + 7일 안 일만 `[World State]` 메모로 써서, 보내는 꾸러미의 마지막 유저 메시지 앞에 끼운다.
     먼 미래는 안 들어간다. 비밀 이벤트에는 아는 사람 목록이 붙는다.
   - 꾸러미 안 이전 상태창들의 UPCOMING 칸은 지운다.
   - 메모는 채팅에 저장되지 않고 보낼 때마다 새로 만든다 → 리롤·삭제해도 안 꼬인다.
2. **화면에 그릴 때** (`editDisplay`)
   - 상태창에 UPCOMING이 없으면 그 메시지 날짜 기준 다음 일정 3개를 붙여 보여 준다.
   - 그다음 기존 `Status` 정규식이 상태창 카드로 바꾼다. 저장된 원문에는 없으므로 AI는 못 본다.

**막힘 표시**: 유저 행동으로 이벤트가 불가능해지면 AI가 상태창 앞에 `<!-- TIMER: E2 blocked -->`를 쓴다.
화면엔 안 보이고, 메시지 수정 화면에서는 보이므로 직접 넣거나 지울 수 있다.
그 이벤트를 전제로 하는 뒤 이벤트(`needs`)도 같이 막힌다.

## 이벤트 고치기

`원작타임라인.lua` 맨 위 `EVENTS` 표의 한 줄이 이벤트 하나다.

```lua
{ id = "E2", day = 75, date = "7.08", title = "다프네야 → 루스란 접촉", knows = "Daphneya, Ruslan", needs = {"E0"},
  plot = "Through a familiar, Daphneya delivers a note to Ruslan saying that Runian is alive." },
```

| 칸 | 뜻 |
|---|---|
| `id` | 이름표. 막힘 표시에 쓴다 |
| `day` / `date` | D-몇 / 날짜 |
| `title` | 화면 UPCOMING에 나오는 이름 |
| `knows` | 아는 사람. 없으면 공개 행사 |
| `needs` | 이게 막히면 같이 막힘 |
| `plot` | AI에게 보내는 내용 |

따옴표 `"`, 쉼표 `,`, 중괄호 `{ }`는 지우지 않는다. 맨 위 `WINDOW = 7`은 며칠 전부터 알려 줄지,
`UPCOMING_COUNT = 3`은 화면에 몇 개 보여 줄지.
